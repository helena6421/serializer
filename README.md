# Сериализация мультимножества чисел

## Исходное задание

Есть множество (массив, где порядок не важен) целых чисел в диапазоне от 1 до 300. Количество чисел - от 5 до 1000. Простейший алгоритм сериализует множество в строку вида "1,300,237,188". Напишите функцию сериализации / десериализации в строку, чтобы итоговая строка была компактной (итоговая строка должна быть в 2 раза короче простейшей сериализации для любых возможных наборов чисел). Цель задачи - максимально сжать данные относительно простой сериализации без алгоритма сжатия.
Сериализованная строка должна содержать только ASCII символы. Можно использовать любой язык программирования.
Вместе с решением нужно прислать набор тестов  - исходная строка, сжатая строка, коэффициент сжатия.
Примеры тестов: простейшие короткие, случайные - 50 чисел, 100 чисел, 500 чисел, 1000 чисел, граничные - все числа 1 знака, все числа из 2-х знаков, все числа из 3-х знаков, каждого числа по 3 - всего чисел 900.

## Краткое описание решения

Я использовала тот факт, что по условию порядок элементов в массиве не важен. Поэтому исходный массив рассматривается как **мультимножество**: повторы сохраняются, но порядок следования чисел не сохраняется.

Вместо хранения последовательности чисел моё решение строит частотное представление.
После этого частотный вектор преобразуется в одно большое число — комбинаторный ранг мультимножества. Полученный ранг кодируется в строку с использованием печатных ASCII-символов.

Обратная операция выполняется симметрично:

```text
ASCII-строка -> комбинаторный ранг -> частотный вектор -> отсортированный массив чисел
```

Так как порядок массива по условию не важен, десериализация возвращает массив в отсортированном виде.

## Тестовые сценарии

В тестах проверяются следующие группы случаев:

### Обычные случаи

- короткие массивы;
- массивы со смешанными значениями;
- массивы с повторами;
- массивы без повторов.

### Случайные случаи

- 50 чисел;
- 100 чисел;
- 500 чисел;
- 1000 чисел.

### Граничные случаи

- все числа однозначные;
- все числа двузначные;
- все числа трёхзначные;
- каждое число от `1` до `300` встречается по 3 раза;
- минимальная длина массива;
- максимальная длина массива.

### Негативные сценарии

- массив короче 5 элементов;
- массив длиннее 1000 элементов;
- число меньше 1;
- число больше 300;
- дробное число;
- некорректная сериализованная строка.
